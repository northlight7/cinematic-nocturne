# Nocturne Atelier

Fragrance & luxury · Independent concept demo

A night-blooming fragrance study that loosens into a scent ribbon around a portrait bottle.

**[Visit the live site ↗](https://northlight7.github.io/cinematic-nocturne/)** · [Project notes & screenshots](https://github.com/northlight7/web-design-portfolio/tree/main/projects/nocturne) · [Full portfolio](https://northlight7.github.io/web-design-portfolio/)

## What to try

Scroll to the composition and move between the notes to change the atmosphere.

## Design focus

The cap lifts away and the bloom opens around the bottle. Each note restages the light and the surrounding petals instead of switching a colour swatch. Native pointers only: there is no custom cursor. Motion can be paused from the navigation, and the page keeps its content and controls when motion is off.

## Run locally

This is a buildless static site. Serve this repository with a static HTTP server, for example:

```sh
python3 -m http.server 8080
```

Then open http://localhost:8080 in your browser. Fonts, dependencies and all visual assets are hosted locally with the site. Nothing is fetched from a third-party runtime.
